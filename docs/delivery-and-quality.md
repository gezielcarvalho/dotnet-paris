# Livraison et qualité

## Maturité

Ce dépôt est un exercice pédagogique historique. Les composants présents sont utiles pour discuter de SOLID, d'ASP.NET Core et de Docker, mais ne constituent pas une application commerciale prête à être déployée.

## Conditions avant toute reprise

1. Définir un périmètre de produit réel et réduire les promesses de la documentation à ce qui est livré.
2. Compléter le domaine, l'intégration Angular et les tests automatisés.
3. Mettre en place une base de données durable, la sécurité, la configuration par environnement, CI et l'observabilité.
4. Évaluer les dépendances et l'architecture avant une modernisation.

## Validation de cette modification

Vérifier les liens Markdown et les espaces via le diff. Aucun changement de code ou de configuration n'est inclus.
