## État

Le dépôt est un exercice .NET 8 en français avec une API de produits et météo, une couche service/repository, Entity Framework en mémoire, un squelette Angular et des fichiers Docker. Il ne contient pas l'ensemble du magasin virtuel décrit dans le README principal.

Il doit être conservé comme référence/archive pédagogique, et non comme vitrine d'une application e-commerce complète.
