# Charte du projet

## But pédagogique

Explorer C#, ASP.NET Core, architecture en couches, principes SOLID, Entity Framework, Angular et Docker dans le contexte d'un exercice de magasin virtuel.

## Périmètre vérifié

- API .NET 8 avec contrôleurs produits et météo.
- Classes `Product`, repository et service, dont un exemple de filtrage de produits publics/privés.
- Persistence Entity Framework en mémoire.
- Squelette Angular moderne et orchestration Docker locale.
- Note pédagogique en français sur les principes OCP et LSP.

## Non implémenté dans le code actuel

- Panier, commandes, paiements, notifications, promotions, gestion de stock complète et interface de magasin intégrée.
- Démonstrations complètes des cinq principes SOLID annoncés dans le README.
- Tests, CI/CD, base de données durable et exploitation de production.

## Décision de portefeuille

Classer le dépôt comme référence/archive pédagogique. Les exemples SOLID et l'expérience francophone peuvent être réutilisés dans une présentation consolidée, mais le dépôt ne doit pas être présenté comme une application e-commerce finalisée.
